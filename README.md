# aegisreader
Ridi, Yes24, Aladin DRM

아래 링크는 리디, 예스24, 알라딘 전자책의 DRM 해제 방법을 토대로 Gemini를 채찍질하여 만들어본 웹앱이다.  
전자책을 **구매**했음에도 DRM 때문에 소유욕을 만족시키지 못하거나 필기앱에 넣어 사용할 사람들에게 추천한다.  
구매를 강조한 것은 **구독형**인 윌라나 밀리의 서재는 대상에 추가하지 않겠다는 뜻이다.  

## FAQ
Q. 어떻게 쓰는지 잘 모르겠다  
A. GUI 사용을 추천한다. 윈도우와 맥을 지원한다. (https://github.com/copilot11111111/aegisreader/releases/latest)  
프로그램을 실행하면 자동으로 책 목록을 읽어오고 '파일에서 추출' 버튼을 클릭하면 Device ID도 알아서 확인해준다.  

Q. 내 개인정보 털리는 거 아니냐? / 내 책 유출되는 거 아니냐?  
A. 프리미엄 활성화와 쿼터 제한을 위한 **Device ID** 말고는 모두 In-Memory로 처리되어 하드에 남지 않고 날아간다. 다운로드가 한 번만 가능하고 15분후 만료되는 것이 바로 이것 때문이다.  
Device ID 또한 프리미엄 기간이 끝났거나 1시간이 지나면 자동으로 삭제된다. **못 믿겠다 싶으면 안 쓰는게 제일이다.**  

Q. Device ID를 확인할 수 없다고 한다  
A. 전자책 뷰어앱에서 책을 1권 이상 다운로드 한 다음에 뷰어를 종료하고 다시 해보면 된다.

Q. 퀘스트가 뭐냐?  
A. 베스트셀러나 필자 추천 도서 등, 퀘스트 대상 도서를 업로드해서 복호화에 성공하면 프리미엄이 활성화 된다.  
프리미엄은 1시간에 50권으로 설정된 쿼터 제한을 무시하고 무제한으로 복호화할 수 있게 된다.  
'내가 이 책은 꼭 추천한다' 싶은 책이 있다면 아래 연락처로 책 제목을 알려주면 퀘스트 대상 도서에 추가할 수 있다.  

Q. 다른 거 물어보려면  
A. 답장이 필요 없다면 이메일 vv.dust176@passmail.com 으로 보내면 되고 답장이 필요하다면 [Session](https://getsession.org/) 이라는 채팅 프로그램을 설치해서 + 버튼 ▶ 새로운 메시지 ▶ 계정 ID 입력란에 '054424c61e9a924ce8395ed8e978ec64eab4372762727ab6084d104c5a54a93553' 입력해서 말 걸면 된다.

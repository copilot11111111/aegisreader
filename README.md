# aegisreader
Ridi, Yes24, Aladin DRM

아래 링크는 리디, 예스24, 알라딘 전자책의 DRM 해제 방법을 토대로 Gemini를 채찍질하여 만들어본 웹앱이다.  
재미로 '프리미엄'을 추가해서 "그것"의 맛을 내보긴 했지만 쿼터 제한 해제나 실험 기능 개방 외 추가 기능은 없다.  
전자책을 **구매**했음에도 DRM 때문에 소유욕을 만족시키지 못하거나 필기앱에 넣어 사용할 사람들에게 추천한다.  
구매를 강조한 것은 **구독형**인 윌라나 밀리의 서재는 대상에 추가하지 않겠다는 뜻이다.

## How to
URL: https://aegisreader.com/  
[Windows 기준]
1. 구매한 전자책 플랫폼 선택 (리디, 예스24, 알라딘 中)
2. **"경로 복사 후 폴더 선택"** 버튼 클릭
3. 폴더: 우측 입력란에 **붙여넣기(Ctrl+V)**후 업로드 선택
4. **"<폴더명>"의 모든 파일을 업로드하시겠습니까?** 팝업 뜨면 "업로드" 선택
5. Device ID 입력
6. **복호화 시작** 버튼 클릭
7. 업로드 및 복호화 완료되면 **다운로드** 클릭

[Device ID 확인하기]
1. **복호화 인증 정보 입력** 카드에서 **Device ID 확인하기** 버튼 클릭
2. 플랫폼 선택 (리디, 예스24, 알라딘 中)
3. **경로 복사** 클릭
4. **찾아보기...** 클릭후 파일 이름: 우측 입력란에 **붙여넣기(Ctrl+V)**후 열기 선택
5. **Device ID 추출하기** 클릭
6. 목록에서 Device ID 선택후 **선택한 ID 즉시 적용하기** 클릭
